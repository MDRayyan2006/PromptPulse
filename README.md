# ⚡ PromptPulse — AI Prompt Highlighter

**Highlight AI prompts. Learn faster. Revisit anytime.**

PromptPulse is a powerful Chrome extension that lets you highlight important prompts, responses, and web content — turning your browsing and AI interactions into a structured learning experience.

---

## 🚀 Features

✨ Highlight any text across websites
🧠 Save important AI prompts & responses
📌 Persistent storage using Chrome storage
📂 Access highlights anytime via side panel
⚡ Works across all websites (`<all_urls>`)
🎯 Built for students, developers, and AI users

---

## 🧩 How It Works

1. Select any text on a webpage or AI chat
2. Highlight it using PromptPulse
3. Access saved highlights in the side panel
4. Revisit and learn anytime

---

## 🛠️ Tech Stack

* Chrome Extension (Manifest V3)
* JavaScript (ES Modules)
* Chrome APIs:

  * `storage`
  * `activeTab`
  * `scripting`
  * `sidePanel`

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/yourusername/promptpulse.git
```

2. Open Chrome and go to:

```
chrome://extensions/
```

3. Enable **Developer Mode**

4. Click **Load unpacked**

5. Select the project folder
